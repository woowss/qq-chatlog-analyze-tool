# 人物画像上下文

私聊人物锐评与群成员画像会先按时间均匀选择目标人物发言，再在剩余字符预算内补充上下文。明确回复引用的原消息优先；然后按同一 30 分钟对话段补目标消息之前最多两条、之后最多一条。缺失或重复消息 ID 会跳过显式回复定位，继续尝试邻近消息。最终按原消息顺序输出，每条标为 `[目标人物]` 或 `[仅供上下文]`。

只有 `[目标人物]` 消息计入画像样本数、发言量和个人语言特征；上下文消息只用于理解语气、引用、玩笑和回复关系。选择器用同一套代码服务私聊、群聊与证据引用核验。候选上下文无法放进既有字符预算时会跳过，目标消息优先。

策略版本纳入 `profile` 和 `member_profiles` 的结果缓存身份。分层抽样会尽量取满目标样本上限；上下文会话间隔复用本地统计的唯一阈值。旧缓存不迁移为新策略结果：页面仍可显示旧结果并标注为旧策略；重新运行才会建立新结果缓存。要回退到仅目标消息输入，可设置 `QQCHAT_PERSON_CONTEXT=0`，此时恢复旧选择与旧缓存身份。默认不因上下文改动重算 habits 或其他分析维度。
