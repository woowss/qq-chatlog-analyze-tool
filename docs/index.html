QQ 聊天记录分析工具

导入 QQChatExporter 导出的 JSON 聊天记录，通过本地统计分析 + DeepSeek AI 实现多维度聊天洞察， 以 ECharts 可视化图表清晰呈现。

🐍 Python 3.10+ 🌶️ Flask 3.x 📈 ECharts 5 🤖 DeepSeek AI 📜 GPL v3
✨ 功能介绍 🚀 快速开始 📦 GitHub

✨ 功能特性

从本地统计到 AI 深度分析，全方位了解你的聊天数据

📈

总览仪表盘

消息总数、聊天天数、日均消息、图片数量一目了然。双方消息数和发言字数直观对比。

⏰

活跃时段分析

24 小时分布柱状图 + 星期分布，了解双方最活跃的时段和每周聊天规律。

😊

表情排行

统计双方常用表情 Top 10，看看谁的表达更丰富、谁最爱用某个表情。

💬

对话节奏

统计对话轮次、平均回复速度、句长分布，分析双方的沟通模式差异。

☁️

高频词云

使用 jieba 分词提取高频词汇，以词云图直观展示聊天中的核心话题。

📄

全篇报告

一键生成包含所有统计 + AI 分析的报告，支持浏览器打印 / 导出 PDF / 下载 HTML。

😊

情绪分析

逐月分析双方情绪变化与强度曲线，追踪情绪波动趋势和关键词。

👥

人际关系

分析互动模式、话题发起倾向、亲密程度变化，判断双方在关系中的角色。

🧑

个人习惯

分析说话风格、口头禅、标点习惯、回复模式，构建独特的语言指纹。

📈

话题趋势

按月提取核心话题及占比，追踪话题演变，发现对话中的关注点转移。

🎯

人物锐评

深度性格画像，涵盖优缺点、思维特征、情绪模式、关系动态等多维度分析。

🏗️ 系统架构

轻量设计 · 无外部数据库 · 数据本地优先

# 启动入口 app.py
│
├── /upload → parser/qq_parser.py # 解析 QQChatExporter JSON
│ └──→ ChatData (dataclass) 存入 Flask session
│
├── 本地统计 → analyzer/local_stats.py # 无需网络 / API Key
│ └──→ 每日趋势 · 时段分布 · 表情排行 · 句长统计 · 回复速度
│
├── AI 分析 → analyzer/deepseek_client.py # 调用 DeepSeek API
│ └──→ 情绪 · 关系 · 习惯 · 话题 · 锐评
│ └──→ analyzer/prompts.py # System Prompt 模板
│
└── 前端 → web/templates/*.html # Jinja2 模板
└──→ web/static/js/charts.js # ECharts 图表渲染
└──→ web/static/css/style.css # 自定义样式

# 数据流
JSON → ChatData → 本地统计 / AI API → ECharts

🚀 快速开始

5 分钟即可上手，无需数据库配置

1

导出聊天记录

使用 QQChatExporter 导出私聊记录为 .json 文件。

2

安装依赖

pip install -r requirements.txt
3

配置 API Key（可选）

在项目根目录创建 .env 文件：

DEEPSEEK_API_KEY=你的DeepSeek_API_Key
DEEPSEEK_MODEL=deepseek-chat
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1

不配置 API Key 也能使用本地统计功能。

4

启动应用

python app.py

浏览器打开 http://localhost:5000

5

开始分析

上传 JSON 文件 → 查看仪表盘 → 点击 AI 分析获取深度洞察。

数据安全承诺

  • 聊天记录只保存在本机：作者不收集、不接收任何数据
  • 只有启用 AI 分析时，对话文本才会发送到你自己配置的接口（如 DeepSeek）；多媒体文件不会被上传
  • 所有会话数据存储在 flask_session/ 目录，重启后自动清理
  • 无外部数据库依赖，无需注册账号
